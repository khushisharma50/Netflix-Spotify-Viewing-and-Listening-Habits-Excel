# 🎵🎬 Personal Streaming Analytics Dashboard (Netflix & Spotify)

An end-to-end data analytics project exploring personal streaming behavior by extracting raw consumption logs, cleaning and transforming data via Excel Power Query, and building an interactive executive dashboard in Microsoft Excel.

---

## 📌 Project Overview
Streaming platforms collect massive amounts of user interaction data. This project investigates viewing and listening habits to answer key behavioral questions:
* What are my peak streaming days and hours?
* How is my time split between video binge-watching (Netflix) and music streaming (Spotify)?
* Which genres, shows, and artists dominate my media consumption?

---

## 🛠️ Tech Stack & Methodology
* **Data Extraction & Transformation (Power Query):** 
  * Utilized **Excel Power Query (Query Editor)** to import, clean, and normalize raw JSON/CSV activity exports.
  * Performed data type transformations, removed unnecessary columns, handled null/missing values, and engineered custom conditional columns (e.g., separating weekdays vs. weekends).
* **Advanced Excel Analysis:** 
  * Built structured relational tables and **Data Models** to connect datasets.
  * Utilized **PivotTables** and calculated fields to aggregate viewing durations, hourly patterns, and day-of-week trends.
  * Applied **Conditional Formatting** and dynamic formulas for deeper segmentation.
* **Visualization:** Custom interactive Excel Executive Dashboard featuring KPI summary blocks and clean visual charts.

---

## 📊 Key Insights & Findings
1. **Temporal Trends:** Identified clear behavioral shifts between weekday evening listening sessions and heavy weekend binge-watching.
2. **Platform Breakdown:** Quantified the exact distribution of active music streaming versus video consumption time.
3. **Top Content:** Highlighted top-ranking show franchises and music artists occupying the highest percentage of total consumption.
